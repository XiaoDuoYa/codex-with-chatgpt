# C2C Plus-Compatible Multi-Transport V0.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a transport-independent C2C runtime with a backward-compatible MCP adapter and a GitHub branch workflow that lets ChatGPT Plus users complete INIT → PLAN → EXECUTED → REVIEW → DONE without Developer Mode.

**Architecture:** Runtime protocol parsing, validation, serialization, and task lifecycle live above a minimal transport contract. MCPTransport wraps the existing bridge/tunnel/OAuth/pairing path without changing behavior; GitHubTransport publishes validated task snapshots and declared code changes to a dedicated branch while Codex remains the only execution layer.

**Tech Stack:** Node.js >= 20, TypeScript 5.9, Commander 14, Zod 3.25, Vitest 3.2, Git CLI, pnpm 11.

## Global Constraints

- FilePackTransport is not implemented or scaffolded in V0.2.
- Existing `c2c setup/start/status/doctor/pair/unpair` arguments and JSON output remain backward compatible.
- Bridge, Tunnel, OAuth, Pairing, MCP tools, containment, and sensitive-file behavior are not rewritten.
- No ChatGPT browser automation, Cookie access, Session Token access, private API access, DOM scraping, or unofficial API wrapper.
- GitHub mode never force-pushes, merges, deletes branches, stashes user changes, or modifies main/master.
- Git staging uses explicit paths only; never use `git add .` or `git add -A`.
- `.c2c/current.json` is the active task machine truth; Markdown and task copies are rebuildable projections.
- DONE is a pending review decision until fresh final tests pass.
- Every production behavior follows RED → GREEN → REFACTOR, with a focused commit after the task gate passes.
- The release gate includes a real GitHub repository and real ChatGPT Plus manual-relay E2E.

export const C2CStateSchema = z.enum(["INIT", "PLAN", "EXECUTING", "EXECUTED", "DONE", "BLOCKED"]);
export const C2CMessageSchema = z.object({

export function parseC2CMessage(text: string): ParseResult;
